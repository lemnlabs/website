| 메서드   | 설명                                                                      |
| -------- | ------------------------------------------------------------------------- |
| `GET`    | 서버의 리소스를 조회할 때 사용한다.                                       |
| `POST`   | 서버에 새로운 리소스를 등록(생성)하거나 요청 데이터를 처리할 때 사용한다. |
| `PUT`    | 리소스를 완전히 대체(덮어쓰기)한다. 대상이 없을 경우 새로 생성한다.       |
| `PATCH`  | 리소스의 일부분만 수정(변경)한다.                                         |
| `DELETE` | 서버의 리소스를 삭제할 때 사용한다.                                       |

> [!info] `PUT`과 `PATCH`의 차이
> `PUT`은 리소스 전체를 교체하고, `PATCH`는 리소스의 일부만 수정한다.
>
> 예를 들어, 현재 사용자 정보가 `{ "name": "John", "age": 24 }`일 때:
>
> - `PUT /users/1`에 `{ "name": "Alex", "age": 24 }`를 보내면 사용자 정보를 통째로 교체한다.
> - `PATCH /users/1`에 `{ "name": "Alex" }`를 보내면 이름만 변경하고 나머지 정보는 유지한다.
>
> `PUT`은 일반적으로 ==멱등성==을 갖는다. 실제 처리 방식은 API 규칙을 확인해야 한다.
